# Codex Pets: Synki and Clawd

Local source and sprite-sheet archive for two custom ChatGPT Work/Codex pets. This repository is local only; it has no GitHub remote.

| Pet | Current service ID | Files |
| --- | --- | --- |
| Synki | `pet_6b0258f848ac8191acac85cc26352242` | `pets/synki/spritesheet.png`, `pets/synki/pet.json` |
| Clawd | `pet_6b0649e9dc408191ae912758c46e1895` | `pets/clawd/spritesheet.png`, `pets/clawd/pet.json`, `pets/clawd/source/` |

The two top-level `spritesheet.png` files were downloaded from the current Pets records on 2026-11-25. Both are v2 1536×2288 RGBA sheets. `pets/clawd/source/` is a curated copy of the local Clawd build work from `~/Projects/pet-runs/clawd`, including source GIFs, scripts, prompts, intermediate frames, and final sheets. Caches, logs, encoded duplicate GIFs, and QA previews were omitted. The downloaded Clawd sheet and the local final source sheet have different file hashes, so both are retained.

Synki's original creation source was not found locally; the current service sprite sheet and metadata are preserved here. The pet IDs are identifiers for the online records and are not needed to view the local images.

Clawd's source artwork came from [Mascot Studio](https://github.com/Harriszed/mascot-studio). Its [NOTICE](https://github.com/Harriszed/mascot-studio/blob/main/NOTICE.md) says redistribution rights for the artwork are unverified. Keep this repo local unless those rights are resolved.
